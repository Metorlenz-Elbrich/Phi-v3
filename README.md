# PhiBrain

Premium technology engineering, digital design, and cybersecurity studio.

**We Design. We Build. We Secure. We Scale.**

---

## Quick start

```sh
npm install
npm run dev
```

Then open <http://localhost:3000>.

## Stack

Next.js 15 (App Router) · TypeScript · Tailwind CSS · Framer Motion · GSAP / ScrollTrigger · React Three Fiber · Lenis.
